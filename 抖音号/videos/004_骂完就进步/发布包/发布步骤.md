# 004 怎么发（给发布的人或机器人）

这个文件夹里的东西齐了就能发，不用再找别的文件。字段以 `发布.json` 为准；`标题.txt`、`简介.txt` 是同样的内容，方便整段复制。

## 文件
| 文件 | 用在哪 |
|---|---|
| `004_骂完就进步_v2.mp4` | 要发的视频：竖屏 1080×1920，36.2 秒 |
| `标题.txt` | 作品标题，29 字（上限 30） |
| `简介.txt` | 作品简介，568 字（上限 1000），最后一行是 5 个话题 |
| `封面_3比4_1080x1440.png` | 竖封面 |
| `封面_4比3_1440x1080.png` | 横封面 |
| `封面_9比16_1080x1920.png` | 只能选整屏封面时用 |
| `置顶评论_可选.txt` | 可选，号主说要才发 |

## 步骤
1. 上传 `004_骂完就进步_v2.mp4`。传完核对时长显示 00:36。
2. 标题：贴 `标题.txt` 的全文。
3. 简介：贴 `简介.txt` 的全文，段落之间的空行要保留。
   - 最后一行的话题如果没有变成话题（没有变色、点不动），把那一行删掉，改成一个一个输入：`#家庭教育`、`#考试`、`#回归均值`、`#心理学`、`#概率`，每个后面跟一个空格。
   - 只有一个描述框、没有单独的标题框时：第一行贴标题，空一行，再贴简介。
4. 封面：能上传封面就传竖封面和横封面；只能从视频里选一帧时，用第一帧。
5. 声明：在“自主声明”（手机端叫“作品声明”）里选“内容由AI生成”。这一项必须选。
6. 其他设置：公开；允许保存；不同时发布到其他平台；位置、热点、合集都不填。
7. 发布前再核一遍四样：标题；简介第一句是“你小时候考砸了，等来的是骂，还是抱？”；声明已选；时长 00:36。
8. 发布。建议时间：2026-11-13 21:00（北京时间，周五）。前三条都在 20:24 到 21:25 之间发，放在同一时段数据才好比；号主可以改。

## 不要做的
- 只做发布这一件事：不点赞、不关注、不评论、不私信、不改账号资料。
- 碰到验证码、扫码登录、风险提示就停下，交给号主本人。
- 发布失败最多再试 1 次；还不行就停，把页面上的提示原文带回来。
- 置顶评论不要自己决定发，号主明确说要才发。

## 发完带回来的
- 发布时间（精确到分钟）和作品链接；
- 内容管理里的状态：审核中、已发布，还是没通过；
- 话题有没有变成能点的链接；
- 发布满 24 小时、72 小时各读一次：播放、点赞、评论、分享、收藏、完播率、2 秒跳出率、涨粉，和评论原文。
